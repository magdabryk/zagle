# Ski & Sail — nowa strona

Lekka, responsywna strona wizytówka Sport Time, Ski & Sail. Projekt wykorzystuje wyłącznie HTML, CSS i JavaScript — bez frameworków i procesu budowania.

## Podgląd lokalny

Otwórz `index.html` w przeglądarce albo uruchom prosty serwer w katalogu projektu, na przykład:

```sh
python3 -m http.server 8000
```

Następnie przejdź pod adres `http://localhost:8000`.

## Publikacja na GitHub Pages

Najprościej umieścić zawartość tego katalogu w osobnym repozytorium GitHub, a następnie:

1. Otworzyć **Settings → Pages** w repozytorium.
2. W sekcji publikowania wybrać **Deploy from a branch**.
3. Ustawić gałąź `main` i katalog `/(root)`, a potem zapisać ustawienia.

Plik `.nojekyll` jest już dodany. Strona nie wymaga backendu. Formularz kontaktowy nie jest używany — przyciski otwierają e-mail lub połączenie telefoniczne.

## Przed publikacją

- Potwierdź, że dane kontaktowe i teksty są aktualne.
- Zastąp zdjęcia zewnętrzne własnymi, jeśli chcesz przechowywać wszystkie materiały razem ze stroną.
- Dodaj pliki z aktualną ofertą, terminami i cenami po ich zatwierdzeniu.
